# learn-ML

## 📌 Overview
`learn-ML` is a practical collection of **Jupyter Notebooks** designed to teach essential concepts of **Machine Learning** step-by-step.  
It covers both fundamental statistics and key ML algorithms, making it an excellent resource for beginners and educators alike.

## 🎯 Who is it for?
- Students starting their Machine Learning journey.
- Developers who want hands-on examples before moving to advanced models.
- Teachers looking for ready-to-use educational notebooks.

## 📂 Project Structure
The repository contains numbered notebooks, each focusing on a specific topic:
1. **Mean, Median, Mode**
2. **Standard Deviation**
3. **Multiple Regression**
4. **Feature Scaling**
5. **Train-Test Split**
6. **Decision Tree**
7. **Confusion Matrix**
8. **Hierarchical Clustering**
9. **Logistic Regression**
10. **Grid Search**
11. **Categorical Data**
12. **K-Means Clustering**
13. **Bootstrap Aggregation**
14. **Cross-Validation**
15. **AUC-ROC**
16. **K-Nearest Neighbors (KNN)**

## 🛠️ Technologies Used
- Python 3.x
- Jupyter Notebook
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
