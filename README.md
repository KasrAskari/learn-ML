# learn-ML

## 📌 Overview
`learn-ML` is a curated collection of **Jupyter Notebooks** designed to make the journey into **Machine Learning** clear, practical, and beginner-friendly.  
Each notebook focuses on a specific concept, starting from **fundamental statistics** and progressing to **core ML algorithms**.  
The project emphasizes learning through **hands-on examples**, **step-by-step explanations**, and **visualizations** that make complex concepts easier to understand.

Whether you're a student, self-learner, or instructor, this repository provides a ready-to-use set of resources to strengthen your machine learning foundation.

## 🎯 Goals of the Project
- Break down ML concepts into small, digestible lessons.
- Demonstrate theory with **real code examples** and **visual outputs**.
- Cover both **statistical fundamentals** and **popular ML techniques**.
- Provide a reusable teaching resource for workshops, classrooms, and self-study.

## 📂 Project Structure
Each file is a standalone lesson, numbered in a recommended learning order:

1. **Mean, Median, Mode** – Understanding measures of central tendency.  
2. **Standard Deviation** – Exploring variability and data spread.  
3. **Multiple Regression** – Predicting outcomes with multiple features.  
4. **Feature Scaling** – Standardization and normalization techniques.  
5. **Train-Test Split** – Splitting data for unbiased model evaluation.  
6. **Decision Tree** – Building interpretable tree-based models.  
7. **Confusion Matrix** – Evaluating classification model performance.  
8. **Hierarchical Clustering** – Grouping data using clustering algorithms.  
9. **Logistic Regression** – Binary classification with linear models.  
10. **Grid Search** – Hyperparameter tuning for better performance.  
11. **Categorical Data** – Handling non-numeric features in ML.  
12. **K-Means Clustering** – Partitioning data into k distinct groups.  
13. **Bootstrap Aggregation (Bagging)** – Reducing variance with ensemble learning.  
14. **Cross-Validation** – Robust model evaluation techniques.  
15. **AUC-ROC** – Measuring binary classifier effectiveness.  
16. **K-Nearest Neighbors (KNN)** – Classifying based on similarity.  

## 🛠️ Technologies Used
- **Python 3.x** – Core programming language.
- **Jupyter Notebook** – Interactive coding environment.
- **NumPy** – Numerical operations.
- **Pandas** – Data manipulation and analysis.
- **Scikit-learn** – ML algorithms and utilities.
- **Matplotlib** – Data visualization.
